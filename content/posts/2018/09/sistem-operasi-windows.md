## Apa Itu Windows ?

Jika kamu dilontarkan dengan pertanyaan seperti itu pastinya kalian akan langsung menjawabnya dengan "Sebuah OS Komputer". Dilain sisi jika kamu benar-benar awam dengan [komputer](https://besttutorial.net/pengertian-komputer/) kamu pasti akan menjawab "Jendela-jendela".

Kedua jawaban tersebut tidak ada yang salah keduanya saling melengkapi, karena windows adalah Sebuah Sistem Operasi Komputer yang menjadi jendela untuk dunia digital.

Windows merupakan salah satu keluarga sistem operasi yang dibuat oleh [Microsoft](https://www.microsoft.com/id-id). OS Windows merupakan hasil evolusi dari OS Microsoft yang antarmukanya masih menggunakan CLI _(Command Line Interface)_ yaitu MS DOS.

Semenjak awal mula [sejarah sistem operasi](https://besttutorial.net/sejarah-sistem-operasi/) ada banyak versi sistem operasi windows yang telah dikeluarkan oleh Microsoft.

_Windows Graphic Environment_ 1.0 yang diperkenalkan pada tanggal 10 November 1983 merupakan Windows versi pertama (Windows 1.0).

Dari windows versi 1.0 sampai windows 3.0 masih bergantung pada MS DOS. Jadi OS Windows tidak akan berjalan tanpa adanya MS DOS.

Namun setelah versi ke 4.0 Windows sudah mampu berjalan sendiri tanpa harus ditopang oleh MS DOS.

## Jenis Sistem Operasi Windows

### Berbasis Text / CLI _(Command Line Interface)_

<figure>

![command line interface](/images/command-line-interface.png)

<figcaption>

wikipedia.org

</figcaption>

</figure>

Sistem Operasi pertama berbasis Text adalah DOS _(Disk Operating System)_ yang merupakan sistem operasi yang dimuat dari perangkat penyimpanan komputer.

Selain Microsoft dengan MS DOS-nya, masih ada banyak perusahaan lain yang mengembangkan Sistem Operasi berbasis DOS diantaranya

- IBM PC DOS (Buatan perusahaan IBM)
- DR DOS (Buatan Digital Research Inc.)
- Novell Personal Netware (DR DOS yang dibeli oleh Novell)
- Caldera DOS ( Novell Personal Netware yang dibeli oleh Caldera Corp.)
- Free DOS (DOS _opensource_ yang dikembangkan oleh mahasiswa)

Sistem Operasi berbasis DOS dari Microsoft hanya MS DOS yang dikembangkan dari versi 1.0 sampai versi 3.0, pada versi 4.0 MS DOS sudah mulai menggunakan antarmuka grafik.

<figure>

![logo microsoft dos](/images/logo-microsoft-dos.jpg)

<figcaption>

computerhope.com

</figcaption>

</figure>

MS DOS tidak murni dibuat oleh Microsoft, Microsoft membelinya dari perusahaan Seattle Computer Product (SCP).

Nama awalnya Q-DOS singkatan dari _Quick and Dirty Operating System,_ berubah menjadi MS DOS setelah dibeli oleh Microsoft dengan harga 50.000 dolar Amerika.

Selanjutnya Microsoft menjual lisensi MS DOS kepada IBM untuk melengkapi produk _PC IBM_.

Sejak saat itu Microsoft dan IBM mulai lebih intens dalam bekerjasama, hal ini dibuktikan dengan rilisnya komputer IBM PC yang dibundel dengan MS DOS yang berubah nama menjadi IBM PC DOS.

Selain menjualnya kepada IBM, Microsoft juga menjualnya kepada perusahaan lain, sehingga keluarlah versi-versi DOS dengan nama berbeda seperti TandyDOS, Compaq DOS dan lain-lain.

Namun selang berjalannya waktu Microsoft merubah kebijakan lisensinya, sehingga perusahaan lain tidak bisa menggunakan nama OSnya sendiri melainkan harus menggunakan nama MS DOS.

Hal ini bertujuan untuk membranding produk MS DOS nya sehingga lebih mudah untuk dimonetisasi. Setelah itu Microsoft mulai mengakuisisi produk-produk aplikasi dari berbagai perusahaan untuk melengkapi fitur dari MS DOS. Aplikasi tersebut diantaranya :

- Disk Defragmenter dari Symantec Corporation.
- PC tools dari Central Points (dijadikan Microsoft Antivirus)
- Expanded memory manager dari Quarterdeck
- Drive space dari Stac Electronics (aplikasi kompresi)
- dll.

### Berbasis Grafik / GUI _(Graphical User Interface)_

<figure>

![graphical user interface](/images/gui.jpg)

<figcaption>

thenextweb.com | GUI

</figcaption>

</figure>

Dalam perkembangan Sistem Operasi komputer muncul suatu konsep unik yang dapat lebih mempermudah manusia dalam menggunakan komputer, yaitu dengan adanya antarmuka berbasis grafik.

Jadi komputer menjadi lebih _user friendly,_ dengan menerapkan gambar untuk bisa mengakses dan mengeksekusi program.

Sudah begitu banyak Sistem Operasi berbasis GUI yang dikembangkan oleh berbagai perusahaan dan komunitas dari tahun ketahun seperti OS/2, Macintosh, Windows, amiga, Linux, Symbian, dan lain-lain.

Para peneliti dari _Xerox Palo Alto Research Center_ (PARC) mengembangkan GUI pertama kali pada tahun 70-an tepatya tahun 1973. Dari penelitian inilah muncul era baru komputer grafis.

#### MS DOS 4.0 dan Windows 1.0

<figure>

![windows 1.0](/images/windows-1.0.png)

<figcaption>

Microsoft mulai beralih dari CLI _(Command Line Interface)_ ke GUI _(Graphical User Interface)_ pada tahun 1985 dengan merilis OS nya yang bernama Windows 1.0 dan MS DOS 4.0.

Sistem Operasi Windows berbasis GUI pertama adalah Windows 1.0 tepatnya pada tanggal 10 November 1983, namun mulai dipasarkan ke publik pada tahun 1985.

Windows 1.0 tidak murni berbasis GUI 100% karena masih bergantung pada MS DOS, karena sejatinya fitur GUI pada Windows 1.0 adalah paket GUI tambahan dengan kode _Interface Manager._

Selain itu juga ditambahkan fitur pengoperasian melalui mouse / tetikus. windows 1.0 juga dilengkapi dengan fitur _multitasking,_ sehingga dapat menjalankan beberapa program dalam satu waktu.

Karena berlandasan DOS maka Windows 1.0 juga mendukung MS-DOS, sehingga pengguna tidak perlu keluar windows terlebih dahulu untuk menjalankan program DOS, bisa langsung menjalankan perintah MS DOS melalui windows.

Ada sebuah program yang dimiliki MS DOS versi 4.0 dengan nama DOS Shell yang memiliki tampilan hampir sama dengan windows 1.0.

MS DOS 4.0 merupakan versi dengan perombakan paling banyak karena peralihan dari CLI ke GUI. Berbeda dengan versi setelahnya yang hanya menambahkan beberapa perbaikan  dan tambahan fitur utilitas saja.

#### Versi-versi Sistem Operasi Windows Berbasis GUI

<figure>

![](/images/versi-windows.jpg)

<figcaption>

habibhp.blogspot.com | Versi Windows

</figcaption>

</figure>

**Windows 1.0** Seperti yang telah dibahas pada paragraf sebelumnya, Windows 1.0 merupakan versi pertama Microsoft Windows. Versi ini kurang populer di pasaran, karena banyak kekurangan dalam beberapa fungsionalitas.

**Windows 2.0** Windows versi 2.0 dirilis untuk menggantikan windows 1.0 sehingga lebih populer. Hal ini dikarenakan tambahan fitur aplikasi perkantoran seperti word dan excel.

**Windows 3.0** Versi 3.0 merupakan versi yang menawarkan fitur _multitasking_ dan tentu saja lebih populer dari versi sebelumnya.

**Windows 95** Windows 95 merupakan versi windows yang revolusioner karena fitur _multi tasking_ nya yang lebih banyak program yang dijalankan dalam satu waktu.

**Windows 98** Diluncurkan tanggal 25 Juni 1998, awal rilisnya merupakan windows yang lemot dan sering crash. Karena itu Windows 98 mengalami perbaikan secara besar-besaran sehingga memunculkan versi terbarunya yaitu Windows 98SE.

**Windows** **ME** Sebelum merilis Windows 98SE, microsoft lebih dulu merilis Windows ME dengan menawarkan fitur baru yaitu _plug and play._

**Windows XP** Windows XP merupakan produk windows yang pertama kali membuat versi turunannya yaitu Home dan Professional. Bedanya untuk digunakan antara pengguna rumahan dan pengguna bisnis.

**Windows Vista** Vista membawa perubahan besar terkait _user interface_ dengan tampilan 3d nya. Namun, hal tersebut malah membuat vista menjadi berat dipakai, tidak lebih baik dari windows XP. Sehingga jarang diminati.

**Windows 7** Windows 7 dirilis guna sebagai perbaikan dari windows vista, memiliki kennel NT versi 6.2 SP2 dari Windows Server 2008. Windows 7 memiliki keamanan dan fitur yang baru.

Spektifikasi minimum untuk Windows 7 lebih ringan dari pada Windows Vista. Harganya juga lebih terjangkau dibandingkan dengan Windows Vista.

**Windows 8 dan Windows** **10**

Versi windows yang paling baru saat ini yang mulai menggantikan windows 7. Semenjak windows 7 dirilis yang memiliki kemudahan dalam hal instalasi sehingga memudahkan versi setelahnya dalam melakukan instalasi juga.

Seperti dalam hal melakukan instal windows 8 dan instal windows 10.

 

### Windows Server

<figure>

![](/images/windows-server.jpg)

<figcaption>

dimensidata.com | Windows Server

</figcaption>

</figure>

Windows Server merupakan salah satu jenis produk Microsoft berupa Sistem Operasi yang dikhususkan untuk dijadikan Server dalam suatu [jaringan komputer](https://besttutorial.net/pengertian-jaringan-komputer/).

Arsitektur Windows NT merupakan salah satu Sistem Operasi Server pertama yang dibuat oleh Microsoft yang memiliki kemampuan, fitur, dan pengoperasian yang sama dari sistem operasi server standar.

Seperti pada umumnya server, Windows Server juga menyediakan layanan beroirientasi server.

Contohnya seperti menjadi _hosting_ aplikasi web, pengelolaan pengguna, keamanan dan banyka layanan lainnya terkait server.

Berikut ini adalah produk Sistem Operasi Server yang diciptakan oleh Microsoft :

- Windows NT
- Windows 2000 Server
- Windows Server 2003
- Windows Server 2008
- Windows HPC Server 2008
- Windows Server 2008 R2
- Windows Server 8
